## 本次核查修正

相较 `docs 4` 原始材料，本次正式版做了以下关键修正：

1. 明确同步入口使用 PDF、DOCX、JPG、JPEG、PNG 文本优先/视觉降级；异步入口支持相同格式并统一转图片视觉解析。
2. 将任务 TTL 默认值统一为当前配置中的 120 分钟，并说明它按 `created_at` 计算。
3. 将标签配置能力改为“结构锁定”：新增/删除维度、添加/删除规则固定返回 HTTP 409；仅允许更新既有配置、扣分和重置。
4. 补充 PDF 文本双抽取器比对、扫描 PDF 与图片型 DOCX 视觉降级、DOCX OOXML 安全检查和同步文本字符预算。
5. 补充标签允许值、技能证据校验、最多 12 个技能以及公共响应的版本化 ID 契约。
6. 按实际代码列出 25 个唯一路径上的 28 个 method/path 操作，并标出未鉴权接口和生产风险。
7. 更新测试清单，区分自动化测试、私有黄金集与需要外部模型、MinIO 的手工脚本。
8. 补充当前 Kubernetes CI 缺少 `API_KEY` 注入、仅有单副本内存任务存储等部署限制。
9. 为全部 JSON 成功响应增加 Pydantic Schema，并在契约测试中拒绝空响应模型。
10. 公共打标结果增加 `mappingVersion/dimensionId/tagId`，并提供 `GET /api/tags/mapping`。
11. `source` 收敛为 `rule/llm/hybrid`；工作年限更新为 7 个左闭右开档位。
12. Resume 保持原 Schema，不增加 `employmentType`；时间线重叠排除实习和兼职。

## 更新要求

以下改动必须同步更新对应文档：

- 新增或修改 API：更新接口设计、Postman 说明和测试用例。
- 修改 Resume 或标签输出：更新接口设计、详细设计和 Schema 示例。
- 修改模型、Prompt 或解析降级：更新概要设计、详细设计和评测用例。
- 修改环境变量或部署清单：更新运维部署手册。
- 修改标签值或映射：运行标签映射测试，并更新智能打标专项文档。
