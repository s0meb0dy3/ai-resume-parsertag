## 4. 通用验证要点

1. **响应结构**：`code=0` + `data` 为成功；`code=1` + `errorMsg` 为单项失败。
2. **同步打标结果字段**：标签在 **`result.positiveTags`（含 `tagsArray`）** 和
   **`result.negativeTags`（含 `hitCount`/`deductionScore`）** 顶层，不在 `tagInfo` 下。
3. **异步任务状态**：`status=0 待处理 → 1 解析中 → 2 打标中 → 3 完成 / 4 失败`；
   必须轮询 `GET /api/resume/async/result?taskId=...` 拿到 `status=3`。
4. **Langfuse 每接口必查**：trace 名 = 接口路径（`/api/resume/sync/parse` 等）；
   trace 级 `input`/`output` 应存在（input 为请求特征，output 为完整结果）；
   span 树中每个 `@observe` 函数均应有 input/output，图片以 `[image:redacted]` 占位。

## 6. 一次全量回归（Python 脚本）

以下脚本按序覆盖 5.1–5.12（chat 除外），保存为 `/tmp/regression.py` 直接跑：

```python
import base64, json, time, urllib.request

BASE = "http://localhost:21804"
PDF  = "/mnt/c/Users/HP/Downloads/装配工程师-曾先生-27岁-5年经验-猎聘简历.pdf"
URL  = "https://www.w3.org/WAI/ER/tests/xhtml/testfiles/resources/pdf/dummy.pdf"
B64  = base64.b64encode(open(PDF, "rb").read()).decode()

def post(path, payload, timeout=300):
    req = urllib.request.Request(BASE + path, data=json.dumps(payload).encode(),
                                 headers={"Content-Type": "application/json"})
    with urllib.request.urlopen(req, timeout=timeout) as r:
        return json.loads(r.read())

def poll(task_id, timeout=180):
    for _ in range(timeout // 3):
        time.sleep(3)
        with urllib.request.urlopen(f"{BASE}/api/resume/async/result?taskId={task_id}", timeout=30) as r:
            st = json.loads(r.read())
        if st["data"]["status"] in (3, 4):
            return st["data"]["status"]
    return -1

# 1-4 基础
print("health:", json.loads(urllib.request.urlopen(f"{BASE}/health").read())["status"])
print("models:", len(json.loads(urllib.request.urlopen(f"{BASE}/v1/models").read()).get("data", [])))
print("config:", json.loads(urllib.request.urlopen(f"{BASE}/api/tags/config").read())["data"]["mappingVersion"])
print("mapping dims:", len(json.loads(urllib.request.urlopen(f"{BASE}/api/tags/mapping").read()).get("data", {}).get("dimensions", [])))

# 5 sync/parse（base64 + URL）
d = post("/api/resume/sync/parse", {"resumes": [{"type": "base64", "file": {"name": "曾先生.pdf", "content": B64}}]})
print("sync/parse:", d["success"])
resume = d["results"][0]["data"]["resume"]

# 6 sync/tag
d = post("/api/resume/sync/tag", {"resumes": [{"filename": "曾先生.pdf", "resume": resume}]})
print("sync/tag:", d["success"])

# 7 sync/batch（混合）
d = post("/api/resume/sync/batch", {"resumes": [
    {"type": "base64", "file": {"name": "曾先生.pdf", "content": B64}},
    {"type": "url", "file": {"name": "dummy.pdf", "path": URL}},
]})
print("sync/batch:", d["success"], "/", d["total"])

# 8 async/parse（multipart，字段名 file）
import uuid
boundary = uuid.uuid4().hex
body = (f"--{boundary}\r\nContent-Disposition: form-data; name=\"file\"; filename=\"曾先生.pdf\"\r\n"
        f"Content-Type: application/pdf\r\n\r\n").encode() + open(PDF, "rb").read() + f"\r\n--{boundary}--\r\n".encode()
req = urllib.request.Request(BASE + "/api/resume/async/parse", data=body,
                             headers={"Content-Type": f"multipart/form-data; boundary={boundary}"})
with urllib.request.urlopen(req, timeout=60) as r:
    task = json.loads(r.read())["data"]["taskId"]
print("async/parse:", poll(task))

# 9-11 async/batch → async/batch/tag
d = post("/api/resume/async/batch", {"resumes": [{"type": "url", "file": {"name": "dummy.pdf", "path": URL}}]})
print("async/batch submitted:", d.get("submitted"))
d = post("/api/resume/async/batch/parse", {"resumes": [{"type": "url", "file": {"name": "dummy.pdf", "path": URL}}]})
print("async/batch/parse submitted:", d.get("submitted"))
d = post("/api/resume/async/batch/tag", {"resumes": [{"filename": "曾先生.pdf", "resume": resume}]})
print("async/batch/tag submitted:", d.get("submitted"))

# 14 任务列表
print("tasks:", len(json.loads(urllib.request.urlopen(f"{BASE}/api/tasks").read()).get("data", [])))
print("回归完成（Langfuse 验证请按 5.12 抽查）")
```

## 7. 历史坑汇总（实测踩过）

| # | 坑 | 正确做法 |
|---|---|---|
| 1 | URL 类型字段写成 `file.url` | 必须用 **`file.path`**（`utils/file_utils.py` 读 `get("path")`） |
| 2 | `async/batch`、`async/batch/parse` 传 base64/本地文件 | 这两个接口**只支持 `type=url`**；本地文件走 `async/parse` 或 `async/batch/multiform` |
| 3 | `async/parse` multipart 字段名写成 `files` | 单文件字段名是 **`file`**（`async/batch/multiform` 才是 `files`） |
| 4 | `async/batch/parse` 请求体用 `items` | 字段名是 **`resumes`**（与 `async/batch` 一致） |
| 5 | 在 `tagInfo` 下找标签 | 标签在响应**顶层** `positiveTags`/`negativeTags` |
| 6 | `submitted=0` 以为接口坏了 | 多为 URL 下载临时失败，重试或换网络再验 |
| 7 | 重启容器后任务还在 | 任务存内存，**容器重启后 `async/result`、`/api/tasks` 历史清空** |
| 8 | Langfuse 里看不到 trace 的 input/output | trace 级 IO 由同步根函数/异步任务函数在 span 活跃期写入；纯查询接口（health/result/tasks/tags 配置）无 trace 属正常 |
