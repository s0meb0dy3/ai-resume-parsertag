# 异步多格式视觉解析验证报告

> 验证日期：2026-08-07（Asia/Shanghai）
> 适用代码：当前工作区 FastAPI `3.1.0`
> 验证镜像：`ai-resume-parsertag:v3.1.7-20260807-async-multiform`

## 1. 结论

异步文件链已支持 PDF、DOCX、JPG、JPEG、PNG。五种扩展名均执行扩展名、真实内容、
类型一致性和资源预算校验，之后统一转换为图片并交给多模态模型。异步链不调用
Python 文本抽取器，也不会把 DOCX 的 Mammoth 转换结果作为文本发送给模型。

- 自动化测试：`212 passed`，5 个第三方库弃用警告。
- OpenAPI：仓库快照与 `app.openapi()` 一致。
- Docker：容器 `ai-resume-parsertag` 在 21804 端口健康运行。
- 异步多格式：PDF、DOCX、PNG、JPEG 共 4 份样本全部到达 `status=3`。
- OpenAI 兼容：`async_mode=true` 提交 DOCX 后成功到达 `status=3`。

## 2. 格式与转换矩阵

| 输入 | 真实类型识别 | 本地转换 | 模型输入 |
|---|---|---|---|
| PDF | `%PDF` + PyMuPDF 校验 | 144 DPI 页面图 | `image_url` |
| DOCX | ZIP/OOXML 必需条目及安全预算 | Mammoth HTML + PyMuPDF Story A4 页面；无 HTML 时回退正文图片 | `image_url` |
| JPG/JPEG | JPEG 魔数 + Pillow 完整解码 | RGB 图片 | `image_url` |
| PNG | PNG 魔数 + Pillow 完整解码 | RGB 图片 | `image_url` |

DOCX 的 Mammoth 仅用于本地页面排版，不依赖宿主机安装 Office 或 LibreOffice。
复杂浮动对象、页眉页脚、特殊字体和复杂表格仍需用真实样本持续评测。

## 3. 接口覆盖

| 接口 | 状态 | 说明 |
|---|---|---|
| `POST /api/resume/async/parse` | 已支持 | 单文件上传，解析后打标 |
| `POST /api/resume/async/batch` | 已支持 | URL 批量解析后打标 |
| `POST /api/resume/async/batch/parse` | 已支持 | URL 批量仅解析 |
| `POST /api/resume/async/batch/multiform` | 已支持 | 上传与 URL 混合提交 |
| `POST /v1/chat/completions` + `async_mode=true` | 已支持 | 单份 OpenAI 兼容入口 |
| `POST /api/resume/async/batch/tag` | 不适用文件格式 | 输入已解析 Resume JSON |

提交成功只代表任务入队，业务成功必须轮询
`GET /api/resume/async/result?taskId=...`，直到状态为 `3`；状态 `4` 表示终态失败。

## 4. 核心调用链

```text
API 后缀与大小校验
-> detect_document_type() 真实内容识别
-> parse_async_visual_resume_with_logging()
   -> PDF: parse_pdf_with_visual_llm()
   -> DOCX: parse_docx_images_with_visual_llm()
   -> JPEG/PNG: parse_image_with_visual_llm()
-> _parse_visual_images_with_llm()
-> JSON repair / ResumeData 归一
-> 可选 run_tagging()
-> 结果落盘、任务状态更新、轮询返回完整 JSON
```

关键实现位于 `core/document_text.py`、`core/parser.py`、`api/routes_async.py` 和
`api/routes_openai.py`。

## 5. 资源与失败边界

- 单次视觉调用阈值为 8 张页面图片；超过阈值按顺序分批并发再合并结果。
- DOCX 最多渲染 20 页、累计 8000 万像素。
- 独立图片最多 4000 万像素，最短边不少于 64 像素。
- 扩展名与真实内容不一致、损坏、加密或超过预算的输入在模型调用前拒绝。
- 多页面单批失败当前可能被空结果合并，尚无 `partial_success` 和失败页码。
- 异步任务仍保存在单进程内存中，生产暂按单副本使用。
